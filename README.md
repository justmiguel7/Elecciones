# Padron Electoral
Proyecto realizado por: Miguel Angel Figueredo, Emanuel Tarqui, Ariel Chavez y Maia Mazza
La problematica que nos toco fue hacer una pagina donde un ciudadano pueda entrar con su DNI, elegir su mesa y votar a los candidatos que eliga,
mientras que el Administrador se encarga de ver, administrar y ver el grafico de los votos
